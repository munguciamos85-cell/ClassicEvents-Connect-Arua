# Classic Events Connect — High Quality Edition

This package is a visual/UX upgrade of the latest production build. It keeps the existing backend integration, database SQL, logo, search, booking, provider, dashboard and admin features while giving the site a more premium black/gold responsive design.

## Netlify
Upload this folder/ZIP as the new site. Keep `supabase-config.js` configured with your Supabase project URL and anon/public key.

## Production note
The frontend should never contain a Supabase service-role/secret key. Use the public anon key only in the browser.
